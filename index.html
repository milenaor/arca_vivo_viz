No fue posible leer la API

El servidor de ARCA responde con lentitud irregular: la misma consulta puede tardar 3 segundos o más de 40. Cuando se pasa del límite, el navegador corta la conexión y muestra Failed to fetch. Casi siempre basta con reintentar.

Si falla una y otra vez, comprueba tu conexión a internet. No es un problema de permisos de origen: la API acepta solicitudes desde cualquier dominio, incluido un archivo abierto localmente.

Pulso de la colección

Una lectura del conjunto visible: cuántas obras, cuántos pintores, en cuántos lugares se conservan y qué parte es anónima.

Geografía de las obras

Color: número total de pinturas conservadas (o creadas) en cada país dentro de los filtros; no es la proporción de un tema. Para ver proporciones por tema usa «Explorar». Círculos: lugares donde se conservan; toca un círculo para ver las obras registradas allí. Toca un país para filtrar todo el tablero. Arrastra el mapa para moverlo y usa la rueda o los botones para acercar.

Conecta la API para dibujar el mapa.

Producción por década

Según la fecha inicial registrada. Toca una década para usarla como periodo y vuelve a tocarla para quitarlo. Con un país elegido, el contorno punteado es el total sin ese filtro.

Atlas iconográfico en el tiempo

Composición temática por cuartos de siglo, usando el punto medio de cada intervalo de datación. Toca una celda para filtrar ese tema en esos 25 años, o el nombre de un tema para filtrar solo por él. Vuelve a tocar para quitar el filtro.

Trayectorias de las obras

Lugar de origen registrado a la izquierda y lugar de conservación actual a la derecha. Solo se muestran desplazamientos (origen y conservación distintos); toca una cinta para filtrar ese trayecto. Ojo: el origen es un dato atribuido y en muchos casos conjetural.

Relaciones entre campos

Dos términos se unen cuando aparecen en la misma pintura; el grosor es el número de obras compartidas. Arrastra, acerca con la rueda y toca un nodo para ver ejemplos.

Cruza dos campos de la base: cada nodo es un término y cada línea, las obras en que ambos aparecen juntos. Elige el mismo campo en los dos selectores para ver cómo se relaciona consigo mismo.

Esperando datos.

Análisis comparativo

Para cada valor del campo de la izquierda: cuántas obras tiene (barra izquierda) y cuántos términos distintos del campo de la derecha aparecen en esas obras (barra derecha). Sirve para ver si un grupo pequeño concentra, aun así, casi todo el repertorio.
