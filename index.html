Sin conectar

No fue posible leer la API

Si el mensaje dice Failed to fetch, lo más probable es que el servidor no autorice solicitudes desde este origen (CORS). Hay tres salidas: pedir al equipo de ARCA que agregue el dominio donde publiques este archivo a CORS_ORIGIN en Directus, servirlo desde un dominio ya autorizado, o usar un proxy propio y escribir su dirección arriba.

Filtros activos:

Pulso de la colección

Una lectura crítica del conjunto visible: escala, cronología, precisión documental y desplazamiento geográfico.

Esperando datos.

Geografía de las obras

Color: pinturas por país según el periodo. Círculos: lugares donde se conservan; toca un círculo para ver las obras registradas allí. Toca un país para filtrar todo el tablero. Arrastra el mapa para moverlo y usa la rueda o los botones para acercar.

Conecta la API para dibujar el mapa.

Producción por década

Según la fecha inicial registrada. Toca una década para usarla como periodo y vuelve a tocarla para quitarlo; en gris, el total sin el filtro de país.

Esperando datos.

Atlas iconográfico en el tiempo

Composición temática por cuartos de siglo, usando el punto medio de cada intervalo de datación. Toca una celda para filtrar ese tema en esos 25 años, o el nombre de un tema para filtrar solo por él. Vuelve a tocar para quitar el filtro.

Esperando datos.

Trayectorias de las obras

País de origen registrado a la izquierda y país de conservación actual a la derecha. Se muestran únicamente desplazamientos entre países; toca una cinta para filtrar ese trayecto.

Lo más representado

Conteo de obras por término dentro de los filtros activos.

Campo a observar: elige de qué tabla de ARCA quieres el ranking (escenarios, relatos visuales, gestos, símbolos…). La lista se agrupa igual que el panel de filtros. Términos: cuántos resultados mostrar.

Esperando datos.

Relaciones entre campos

Dos términos se unen cuando aparecen en la misma pintura; el grosor es el número de obras compartidas. Arrastra, acerca con la rueda y toca un nodo para ver ejemplos.

Cruza dos campos de la base: cada nodo es un término y cada línea, las obras en que ambos aparecen juntos. Elige el mismo campo en los dos selectores para ver cómo se relaciona consigo mismo.
